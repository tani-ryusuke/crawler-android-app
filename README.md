# crawler-android-app

XIAO ESP32S3を搭載したクローラーロボットからのリアルタイム映像ストリームを受信し、Android端末上で**YOLOv11を用いた物体検知**を行う、および**UART/UDP通信によるロボットのステータス監視機能**を備えたAndroidアプリケーションです。

## 特徴
本アプリはリアルタイム性と操作性を重視し、以下の技術的工夫を行っています。

* **リアルタイム推論**: ONNX Runtimeを活用し、YOLOv11による高速な物体検知を実現。
* **ハードウェアアクセラレーション**: Android NNAPIを利用し、CPU負荷を軽減。
* **ロボット通信・ステータス監視**: UDP通信により、ESP32S3側からのRSSI（電波強度）や動作モード（走行・アタッチメント・停止モード）、センサー検知アラートをリアルタイムで取得・表示。
* **メモリ・パフォーマンス最適化**:
    * Bitmapの再利用によるGC頻度の低減。
    * フレームスキップ処理によるFPSの安定化。
    * RGB_565フォーマット利用によるメモリ効率化。
* **通信の安定性**: Wi-Fi接続監視によるカメラモジュールとの通信。

## 使用技術
* **言語**: Kotlin
* **AI推論**: ONNX Runtime
* **画像処理**: OpenCV for Android
* **モデル**: YOLOv11s

## 動作環境
* Android 7.0 (API Level 24) 以上推奨
* カメラモジュール: XIAO ESP32S3 (MJPEGストリーミング・UDPステータス送信機能)

## システム構成と連携
本アプリは、単体ではなく以下のハードウェアと組み合わせて動作するビジョンシステムです。

* **専用ワイヤレスコントローラ (ESP32-S3)**: ESP-NOWを用いて操作入力を取得し、本体マイコンへ送信。
* **ロボット本体マイコン (ESP32-S3)**: コントローラの指示で駆動し、アタッチメント等の情報をUART通信でカメラ用マイコンへ転送。
* **カメラ用マイコン (XIAO ESP32S3)**: Wi-Fiのアクセスポイント(AP)として動作。本体からUARTで受け取った情報とMJPEG映像をまとめ、AndroidアプリへUDP/HTTPで送信。
* **Androidアプリ (本リポジトリ)**: 映像の受信・OpenCV前処理・YOLOv11によるリアルタイム物体検知・UIへのステータス表示（電波強度やモード切替など）。
